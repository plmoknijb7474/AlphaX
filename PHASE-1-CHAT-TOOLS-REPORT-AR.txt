ALPHA — تقرير تنفيذ المرحلة الأولى: أدوات AI Chat
================================================

النطاق المنفّذ
--------------
1) Interactive Questions داخل AI Chat:
   - يعرض Alpha نموذجاً تفاعلياً عندما تكون هناك عدة اختيارات أو معلومات مستقلة ضرورية للمهمة.
   - يدعم اختيار إجابة واحدة (Select One Answer)، أو كتابة إجابة مخصصة (Type Your Own Answer / Custom Input).
   - أزرار Next وSkip وSubmit تنقل المستخدم بين الأسئلة وترسل الإجابات ضمن رسالة المحادثة.
   - يقتصر النموذج على 1–8 أسئلة، مع 2–8 خيارات للأسئلة ذات الاختيار الواحد.
   - يعرض النص غير الصالح كرسالة تنبيه ولا ينفذه. لا يسمح ببناء HTML أو JavaScript من مخرجات النموذج.
   - التعليمات التفاعلية مضافة كقدرة فرعية إلى System Prompt الحالي ولا تتجاوز تعليمات المشرف.

2) Workspace داخل AI Chat:
   - مساحة ملفات مستقلة لكل مستخدم ولكل conversation_id.
   - إنشاء ملف جديد، فتح ملف محفوظ، تعديل الاسم والمحتوى، حفظ التعديلات، تنزيل الملف، وحذفه.
   - زر Save to Workspace يظهر على كتل الكود التي يولدها Alpha لحفظها يدوياً.
   - الملفات نصية UTF-8 وتُخزّن في قاعدة البيانات، ولا يتم تنفيذها تلقائياً.
   - تبقى ملفات المحادثة القديمة محفوظة عند بدء محادثة جديدة، وتُحمّل عند العودة إليها.

حدود الحماية والتخزين
---------------------
- 200 ملف كحد أقصى لكل محادثة.
- 2 MiB كحد أقصى لكل ملف.
- 20 MiB كحد أقصى لإجمالي محتويات Workspace للمحادثة.
- رفض المسارات المطلقة، ومسارات ../، والفواصل العكسية، وأجزاء المسار الفارغة أو النقطية.
- رفض أسماء ملفات الأسرار والمفاتيح والشهادات ومجلدات secrets/private/credentials، مع السماح بقوالب البيئة مثل .env.example.
- رفض الملفات الثنائية ومحارف NUL.
- جميع واجهات Workspace تتطلب تسجيل الدخول، وتتحقق من دور المستخدم وملكية الملف والمحادثة.
- عمليات POST وDELETE محمية بآلية CSRF الموجودة في التطبيق.
- قيود الاسم والحجم وعدد الملفات تطبق في الخادم، وليس في الواجهة فقط.
- إضافة جدول chat_workspace_files وفهرسه تلقائياً عند تهيئة قاعدة البيانات.
- تحديث migrate_sqlite_to_supabase.py لنقل ملفات Workspace إن كان الجدول موجوداً في قاعدة SQLite المصدر.

الملفات التي أضيفت أو عُدّلت
--------------------------
- app.py: واجهة الأسئلة التفاعلية، Workspace، واجهات API، وقاعدة البيانات.
- chat_workspace.py: التحقق من الأسماء والمحتوى والحدود.
- test_chat_workspace.py: اختبارات التحقق الخاصة بملفات Workspace.
- migrate_sqlite_to_supabase.py: نقل بيانات Workspace ضمن ترحيل SQLite إلى Supabase.
- README-ar.txt وDEPLOY-RENDER-SUPABASE-AR.md: تحديث إرشادات الاستخدام والترحيل.

قيود لم يتم التحقق منها
-----------------------
- اختبار HTTP فعلي لمسارات Flask لم يُنفذ؛ بيئة الفحص لا تحتوي على Flask (ModuleNotFoundError).
- لم يتم الاتصال بقاعدة Supabase أو تشغيل ترحيل PostgreSQL فعلي.
- لم يتم اختبار الواجهة داخل متصفح أو هاتف فعلي.
- لم يتم نشر التغييرات إلى Render أو GitHub.
