تحديث Alpha 3.1 Max — مزود Xkiro وسلسلة النموذج الاحتياطي وSystem Prompt العام

1) اتصال Alpha 3.1 Max
- المزود: Xkiro.
- عنوان API: https://api.xkiro.com/v1/chat/completions
- المحاولة الأولى دائماً: qwen/qwen3.7-max:free.
- المحاولة الثانية الاحتياطية: qwen/qwen3.6-max-preview:free.
- عند فشل الاتصال أو الضغط أو استجابة HTTP غير ناجحة أو انقطاع البث/الاستجابة الفارغة، ينتقل التنفيذ إلى المسار التالي.
- يُعاد ضبط أي نص جزئي عُرض من المسار الأول قبل بدء بث المسار الاحتياطي، حتى لا تختلط الاستجابتان.
- كل مفتاح Xkiro يُنشئ المسارين بالترتيب نفسه. الحد الأقصى 8 مفاتيح، أي مساران لكل مفتاح.
- Project Intelligence لا يدوّر ترتيب هذين المسارين؛ يبدأ دائماً بالنموذج الأساسي ثم الاحتياطي. بقي تدوير مسارات Alpha 2.7 Flash مستقلاً كما كان.

2) System Prompt المشترك
- تمت إضافة حقل عام في لوحة المشرف.
- يُرسل هذا الـSystem Prompt إلى Alpha 3.1 Max وAlpha 2.7 Flash.
- يشمل AI Chat، وProject Intelligence (الكتابة والمراجعة والتحسين والإصلاح)، وDev Code، وتعليمات أدوات البرمجة/الذكاء الاصطناعي.
- تبقى تعليمات كل إصدار الاختيارية إضافات أدنى أولوية من التعليمات العامة.
- تحديث التعليمات العامة يحدّث أيضاً إعدادات الإصدارات التي ما زالت مطابقة للقيمة العامة السابقة، مع الحفاظ على أي تعليمات تخصصية عدّلها المشرف بشكل مستقل.
- اختبار الاتصالات في لوحة المشرف يرسل الـSystem Prompt العام أيضاً.

3) واجهة الإدارة
- استبدال تعليمات Token Harbor القديمة بتعليمات Xkiro.
- إظهار النموذجين الأساسي والاحتياطي بوضوح في مساعدة لوحة الإدارة.
- الإبقاء على Alpha 2.7 Flash ومزود Google دون تغيير مقصود.
- إخفاء مفاتيح التحكم اليدوي بمستوى استدلال Alpha 3.1 Max، لأن مسار النموذج لا يوفّر اختيار مستوى التفكير يدوياً؛ الاستدلال يعمل تلقائياً.

4) ترحيل البيانات
- تُحفظ مفاتيح Xkiro الموجودة مشفّرة، ويُعاد تنظيم مسارات هذا الإصدار إلى زوج أساسي/احتياطي لكل مفتاح.
- يمكن ترحيل قيمة xkiro_api_key_enc القديمة إلى المسارين إذا لم تكن هناك مسارات Xkiro حالية.
- لا تُحوّل مفاتيح Token Harbor إلى Xkiro، لأن مفاتيح البوابات المختلفة لا تُعد قابلة للتبادل. تبقى السجلات القديمة محفوظة لكنها لا تُعتبر مسارات فعّالة لإصدارات Alpha الحالية.
- تم تحديث أداة ترحيل SQLite إلى Supabase لتكوين سلسلة النموذجين ونقل الـSystem Prompt القديم إلى الحقل العام عند الحاجة.
- تم تحديث دليل النشر وREADME مع إعدادات Xkiro الحالية.
- لا تُحذف بيانات المحادثات أو الحسابات أو إعدادات Google.

5) الفحوص المنفّذة
- Python compile: ناجح.
- الاختبارات الموجودة: 61 ناجحة، و20 subtests ناجحة.
- فحص JavaScript المضمّن في Chat وAdmin: ناجح.
- اختبار موجّه لمحاكاة HTTP 503: بدأ المسار الأساسي ثم انتقل للاحتياطي، وتأكد من إعادة ضبط البث الجزئي وإرفاق System Prompt العام مع تعليمات Project Intelligence.
- لم يُجرَ اتصال حي بمفتاح Xkiro حقيقي، ولم يُختبر تشغيل Flask/Render أو قاعدة الإنتاج في هذه البيئة.

ملاحظة توافق: كتالوج هذين النموذجين يدرجهما كنموذجين نصيين؛ لذلك قد ترفض واجهة المزود صوراً مرفقة مع طلب Alpha 3.1 Max. لم تُحذف ميزة رفع المرفقات من الواجهة في هذا التعديل.
